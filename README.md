# حمورابي — نظام إدارة مكاتب المحاماة

منصة عربية لإدارة ملفات الموكلين والقضايا والعقود والمستندات والمواعيد، مع أدوات مساعدة للمحامي.

## المتطلبات

- Node.js حديث أو Bun.
- إعداد مشروع Supabase خاص بالتطبيق.
- متغيرات البيئة الموضحة أدناه.

## الإعداد والتشغيل

1. ثبّت الاعتماديات باستخدام `bun install` أو `npm install`.
2. أنشئ ملف `.env` محلياً وأضف إعدادات Supabase الخاصة ببيئة التطوير:
   - `SUPABASE_PROJECT_ID`
   - `SUPABASE_PUBLISHABLE_KEY`
   - `SUPABASE_URL`
   - `VITE_SUPABASE_PROJECT_ID`
   - `VITE_SUPABASE_PUBLISHABLE_KEY`
   - `VITE_SUPABASE_URL`
3. شغّل بيئة التطوير بواسطة `bun run dev` أو `npm run dev`.

## أوامر مفيدة

- `bun run dev` — تشغيل التطبيق محلياً.
- `bun run build` — إنشاء نسخة الإنتاج.
- `bun run test` — تشغيل الاختبارات.
- `bun run lint` — فحص الشيفرة.

## مكونات النظام

- واجهة التطبيق: React وTanStack Start.
- المصادقة وتخزين البيانات: Supabase.
- إدارة الاعتماديات: Bun أو npm.

لا ترفع ملف `.env` أو أي مفاتيح خاصة إلى مستودع عام. استخدم إعدادات منفصلة للتطوير والإنتاج.
